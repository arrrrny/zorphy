---
title: Polymorphism
---

Zorphy supports closed unions and open hierarchies. In v3 polymorphism is
declarative: a closed set of sibling variants is a `@ZorphyUnion()`, and an open
hierarchy is a `@ZorphyState()` root whose subtypes the generator infers from the
same-library declarations (or that you list with `explicitSubTypes`). This page
combines `sealed_class_example.dart` and the domain entities like `$Attachment`
and `$ChatMessage`.

## Closed union

```dart
@ZorphyUnion()
abstract class $PaymentMethod {
  String get displayName;
}
```

Concrete variants implement the union root:

```dart
@ZorphyEntity()
abstract class $CreditCard implements $PaymentMethod {
  String get cardNumber;
}
```

## Redirecting variant factories & dot-shorthand

A union root re-emits a redirecting `const factory` per variant, so you
construct a variant through the root — and, with Dart 3 dot-shorthand, the
static type does not have to name the union at all (dev.3, #271):

```dart
@ZorphyUnion()
abstract class $AsyncStatus {
  // Redirecting factories target a CONCRETE variant (never an abstract class).
  factory $AsyncStatus.loading() = $Loading;
  factory $AsyncStatus.ready(String value) = $Ready;
}

@ZorphyValue()
class $Loading implements $AsyncStatus {
  const $Loading();
}

@ZorphyValue()
class $Ready implements $AsyncStatus {
  final String value;
  const $Ready(this.value);
}
```

```dart
// Construct through the root ...
final a = AsyncStatus.loading();
final b = AsyncStatus.ready('done');

// ... or through dot-shorthand, where the context is the union type.
AsyncStatus status = .loading();
AsyncStatus other = .ready('done');

// The root also forwards the user-declared static / factory members.
```

## Open hierarchy with explicit subtypes

A `@ZorphyState()` root keeps the base open while still enabling polymorphic
wire dispatch. Subtypes in another library are listed with `explicitSubTypes`.

```dart
@ZorphyState(explicitSubTypes: [$FileAttachment, $LinkAttachment])
abstract class $Attachment {
  String get name;
  String get mimeType;
}
```

```dart
@ZorphyState(explicitSubTypes: [$UserMessage, $AssistantMessage])
abstract class $ChatMessage {
  String get text;
  ChatMessageRole get role;
}
```

## Why this matters

- Safe polymorphic wire dispatch keyed on the `kind` discriminator.
- Strong typing when switching on subtype.
- Clear separation between base contracts and concrete classes.
- Variants constructible through the root (and via dot-shorthand) — no
  variant-class import needed at the call site.
