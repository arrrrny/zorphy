This mirrors `basic_example.dart` and focuses on the essentials: fields, constructors, equality, and patching.

```dart
@ZorphyEntity(principalKey: #id)
abstract class $User {
  String get id;
  String get name;
  int get age;
  String? get email;
}
```

## Highlights

- Instantiate the generated `User` with named parameters.
- `copyWith` produces a modified copy without mutating.
- Equality is structural, not identity-based.
- `UserPatch` captures a partial update as data.

```dart
final user = User(id: 'u1', name: 'Alice', age: 30);
final updated = user.copyWith(age: 31);

// A patch is the v3 way to express a partial update: diff two instances,
// then apply the patch to a target.
final patch = UserPatch.diff(user, user.copyWith(age: 32, email: 'alice@example.com'));
final patched = patch.apply(user);
```
