---
title: Generics
---

From `generic_example.dart`, Zorphy supports generic entities. The wire codecs
carry the type arguments, and converters for generic fields are expressed with
the wire boundary.

## Generic entities

```dart
@ZorphyValue()
abstract class $Result<T> {
  bool get success;
  T? get data;
  String? get errorMessage;
}
```

## Generic converters

A generic field is decoded at the trust boundary; supply the type argument when
you call `fromWire`, and convert the payload yourself if it needs a custom
shape.

```dart
@ZorphyValue()
abstract class $ResultWithConverter<T> {
  bool get success;
  T? get data;
}
```

## Usage

```dart
final result = Result<String>(success: true, data: 'ok');
final wire = result.toWire();
```
