---
title: Nested Objects
---

From `nested_example.dart`, Zorphy handles nested entities, self-references, and nested patching.

```dart
@ZorphyValue()
abstract class $Address {
  String get street;
  String get city;
}

@ZorphyEntity(principalKey: #id)
abstract class $Person {
  String get id;
  String get name;
  int get age;
  $Address get address;
}
```

## Nested patching

A patch diff carries a nested sub-patch for a nested `@ZorphyValue` /
`@ZorphyEntity` field, so applying it updates only the changed leaf:

```dart
final before = person;
final after = person.copyWith(
  address: person.address.copyWith(city: 'Los Angeles'),
);
final personPatch = PersonPatch.diff(before, after);
final updated = personPatch.apply(person);
```

## Self-referencing trees

```dart
@ZorphyEntity(principalKey: #id)
abstract class $CategoryNode {
  String get id;
  String get name;
  List<$CategoryNode>? get children;
  $CategoryNode? get parent;
}
```
