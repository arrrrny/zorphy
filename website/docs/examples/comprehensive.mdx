This page provides a single, comprehensive example demonstrating all major features of Zorphy. It mirrors the `comprehensive_example.dart` file.

## Basic Definition & Patching

```dart
@ZorphyEntity(principalKey: #id)
abstract class $User {
  String get id;
  String get name;
  int get age;
  String? get email;
}

// Usage
final user = User(id: 'u1', name: 'Alice', age: 30);
final patched = UserPatch.diff(user, user.copyWith(name: 'Bob')).apply(user);
```

## Wire Serialization

```dart
@ZorphyEntity(principalKey: #id)
abstract class $Product {
  String get id;
  String get name;
  double get price;
  bool get inStock;
}

// Serialization
final wire = product.toWire();
final product2 = Product.fromWire(wire); // ZorphyBoundaryResult<Product>
```

## Sealed Classes & Polymorphism

```dart
@ZorphyUnion()
abstract class $PaymentMethod {
  String get displayName;
}

@ZorphyEntity()
abstract class $CreditCard implements $PaymentMethod {
  String get cardNumber;
  String get expiryDate;
  @override String get displayName => 'Credit Card';
}
```

## Computed Updates with copyWith

```dart
@ZorphyEntity(principalKey: #id)
abstract class $Counter {
  String get id;
  int get value;
  String get label;
}

// Increment using copyWith
final next = counter.copyWith(value: counter.value + 1);
```

## Nested Objects & Patching

```dart
@ZorphyValue()
abstract class $Address {
  String get street;
  String get city;
}

@ZorphyEntity(principalKey: #id)
abstract class $PersonWithAddress {
  String get id;
  String get name;
  $Address get address;
}

// Nested patching — the patch carries a nested AddressPatch
final patched = PersonWithAddressPatch.diff(before, after).apply(person);
```

## Multiple Inheritance

```dart
@ZorphyValue()
abstract class $Timestamped {
  DateTime get createdAt;
  DateTime? get updatedAt;
}

@ZorphyValue()
abstract class $Identified {
  String get id;
}

@ZorphyEntity(principalKey: #id)
abstract class $Post implements $Timestamped, $Identified {
  String get title;
  String get content;
}
```

## Diffs with the Patch Algebra

```dart
@ZorphyEntity(principalKey: #id)
abstract class $Document {
  String get id;
  String get title;
  int get version;
}

// The patch records the changed fields; changedPaths names their pointers.
final patch = DocumentPatch.diff(doc1, doc2);
// patch.changedPaths → {'/version'}
```
