---
title: JSON Serialization
---

Based on `json_example.dart`, v3 replaces the JSON codecs with the wire codecs:
`toWire()` / `fromWire()`. No JSON codec is generated; the wire form is the
serialization surface.

```dart
@ZorphyEntity(principalKey: #id)
abstract class $Product {
  String get id;
  String get name;
  double get price;
  DateTime get createdAt;
}
```

## Wire serialization

```dart
final product = Product(
  id: 'prod-001',
  name: 'Wireless Mouse',
  price: 29.99,
  createdAt: DateTime(2024, 1, 15),
);

final wire = product.toWire();
final restored = Product.fromWire(wire); // ZorphyBoundaryResult<Product>
```

`fromWire` validates through the trusted constructors and accumulates
`FieldViolation`s at JSON pointers instead of throwing — handle the
`BoundaryErr` case at your trust boundary.
