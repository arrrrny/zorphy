title: Defaults and Converters

This page reflects `complex_example.dart`, `initialization_params_example.dart`,
and `test_json_key.dart`.

In v3 there is no `@JsonKey` — default values are expressed with a field
initializer on the abstract declaration, and custom conversions happen at the
wire boundary.

## Default values

```dart
@ZorphyValue()
abstract class $TreeNode {
  String get value;

  const $TreeNode();

  List<$TreeNode>? get children;
  Duration get timeout;
}
```

A field with an initializer (`Duration get timeout => Duration(seconds: 5);`)
supplies the default the generated constructor uses when the argument is
omitted.

## Custom converters

A field whose wire shape differs from its Dart type is converted at the trust
boundary: decode with `fromWire`, then map the raw value into the field type
yourself (the same pattern plain `json_annotation` classes use for custom
converters).
