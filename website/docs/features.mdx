Zorphy keeps the source declarations tiny and pushes the heavy lifting into generated code. A class carries exactly one v3 archetype — `@ZorphyEntity`, `@ZorphyValue`, `@ZorphyUnion`, `@ZorphyState`, or `@ZorphyIntent` — and there are no presets or `generate*` toggles to keep in sync.

## Core generation

- Immutable concrete classes generated from `$`-prefixed abstract definitions.
- `copyWith` helpers for partial updates.
- Structural equality, `hashCode`, and `toString`.
- Patch classes `<Name>Patch` with `diff` / `apply` / `compose` / `invert`.

## Wire serialization

- `toWire` and `fromWire` for every generated class.
- `fromWire` validates through the trusted constructors and accumulates `FieldViolation`s at JSON pointers instead of throwing.
- Polymorphic wire dispatch for unions and explicit-subtype hierarchies, keyed on the `kind` discriminator.

## Polymorphism

- Closed unions via `@ZorphyUnion()`.
- Open hierarchies via `@ZorphyState()` with `explicitSubTypes` for subtypes the generator cannot infer.
- Exhaustive Dart 3 `switch` over the sealed base.

## Generics

- Generic entities and values.
- Type arguments carried through the wire codecs.

## Query helpers

- A reflection-free `Entity.descriptor` exposing `Field<E, T>` selectors.
- Built-in filter operators: `eq`, `gt`, `lt`, `contains`, `and`, `or`.
- In-memory query helpers for quick iteration.

## Patches and three-way sync

- `<Name>Patch.changedPaths` / `conflictingPaths` for exact three-way merge.
- `compose` / `composePatches` coalesce bursts left-to-right; `invert` captures prior values for undo.

## Quality of life

- Default values via a field initializer on the abstract declaration.
- Static factory methods alongside the generated constructor.
- Nullability that aligns with the generated code and the wire boundary.
