Zorphy turns small, readable Dart definitions into fully featured, immutable data classes. You describe the fields and the archetype. Zorphy generates constructors, `copyWith`, equality, the wire codecs, patch helpers, and more.

## Install

Add the annotation package and generator to your pubspec, then run build_runner. The examples in this repo use the same setup.

## A minimal entity

```dart
@ZorphyEntity(principalKey: #id)
abstract class $User {
  String get id;
  String get name;
  int get age;
  String? get email;
}
```

You get:

- A concrete `User` class with a constructor.
- `copyWith`, `==`, `hashCode`, `toString`.
- The wire codecs `toWire` / `fromWire`.
- A patch class `UserPatch` (`diff` / `apply` / `compose` / `invert`).
