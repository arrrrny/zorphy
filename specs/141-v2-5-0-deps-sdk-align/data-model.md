# Phase 1 — Data Model: zorphy 2.5.0

This release changes configuration and tests only. The "entities" are the artifacts under configuration management, each with invariants that the test suite enforces.

## Entity: PubspecManifest

Represents a package's `pubspec.yaml` (`zorphy`, `zorphy_annotation`, `zorphy_migrator`).

**Fields**
- `name` — package name.
- `version` — semantic version string.
- `environment.sdk` — SDK constraint (e.g. `">=3.11.0 <4.0.0"`).
- `dependencies.*` — name → constraint map (unchanged this release).

**Invariants**
- `zorphy.environment.sdk` admits `>=3.11.0` and excludes `<3.11.0`.
- `zorphy_migrator.environment.sdk` admits `>=3.11.0`.
- `zorphy.version == zorphy_annotation.version` (parity).
- For every declared dependency, `dependency.sdkFloor <= 3.11.0` (the package floor is sufficient).

**State transitions**: `zorphy`/`zorphy_annotation` version `2.4.6 → 2.5.0`; `zorphy`/`zorphy_migrator` `environment.sdk` `">=3.8.0 <4.0.0" → ">=3.11.0 <4.0.0"`. No dependency-constraint transitions.

## Entity: Lockfile (`pubspec.lock`)

The committed resolved baseline per package.

**Invariants**
- `dart pub get --no-example` leaves the lock byte-identical (zero drift).
- Resolved versions remain analyzer 14.7.0 / build 5.0.0 / source_gen 4.3.1 / code_builder 4.13.0 / dart_style 3.1.14 (unchanged).

## Entity: GeneratedOutputFixture

An input entity file paired with its expected `.zorphy.dart` golden.

**Invariants**
- Generated bytes equal the 2.4.6 golden (byte-identical).
- `dart analyze` on the generated output yields **zero** diagnostics under the pinned analyzer (the analyze-clean gate).

## Entity: ReleaseMetadata

Per-package `CHANGELOG.md` plus the version-sync check.

**Invariants**
- `zorphy/CHANGELOG.md` and `zorphy_annotation/CHANGELOG.md` each contain a `2.5.0` entry.
- `scripts/check_version_sync.sh` exits 0 (zorphy == zorphy_annotation == 2.5.0).
